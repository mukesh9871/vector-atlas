Make vectors with Python

Any model works. This example uses sentence-transformers and writes the two files this tab reads, the same format as TensorFlow’s Embedding Projector.

pip install sentence-transformers

from sentence_transformers import SentenceTransformer
texts = open("texts.txt").read().splitlines()
model = SentenceTransformer("all-MiniLM-L6-v2")
vecs = model.encode(texts, normalize_embeddings=True)

with open("vectors.tsv", "w") as f:
    for v in vecs:
        f.write("\t".join(f"{x:.5f}" for x in v) + "\n")
with open("metadata.tsv", "w") as f:
    f.write("\n".join(t.replace("\t", " ") for t in texts))
